🔒 Candidate Setup Lock

⚠️ Lock the candidate setup above before you can open the voting booth.

Once every ward has its candidates registered and approved, lock the setup here. This finalizes the ballot, publishes the public candidate list, and unblocks opening the voting window. Nominations and admin edits are disabled while locked.

🏁 Publish Final Results

The official results have already been published. They are now visible to the public on the Final Results page.

✅ Results Published

This locks in the official results — ward winners and vote totals — and makes them visible on the public Final Results page. This action cannot be easily undone, so make sure voting has closed and all vote counts look correct before publishing.

♻️ Reset Election

This wipes every vote count, clears every voter's "has voted" flag so they can vote again, deletes all vote receipts, and un-publishes any published results. Candidate and voter records themselves are kept untouched. This cannot be undone. Only do this to start a brand-new election cycle with the same parties and voters.

🗑️ Full Reset (Delete Parties & Voters)

Use this when parties are different for a new election cycle. This deletes every party/candidate row and every registered voter permanently — not just votes. Voters will need to register again; you'll need to add new parties from scratch. This is more destructive than "Reset Election" above and cannot be undone.
